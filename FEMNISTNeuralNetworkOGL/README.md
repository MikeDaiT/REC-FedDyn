# FEMNIST-62 Neural Network with Overlapping Group Lasso

This experiment compares `REC_FedDyn`, FedDR, iFedDR, FedNMap, and Zhang on
FEMNIST-62. Each writer is treated as one naturally non-IID client. The model
uses a structured overlapping group-lasso (OGL) regularizer on the first-layer
weights.

This directory contains one formal comparison, one broad step-size sweep, and
two two-dimensional parameter grid searches.

## Files and directories

| Item | Role | Description |
| --- | --- | --- |
| `FEMNISTOGLNeuralNetworkExperiment.py` | **Main experiment** | Runs the five algorithms for sampling levels 200, 100, and 50 across the configured seeds. It creates per-algorithm histories, aggregate CSV files, and comparison plots. |
| `FEMNISTOGLStepsizeTest.py` | **Initial parameter selection** | Performs a one-dimensional overall-step-size sweep for all five algorithms under full client participation. |
| `FEMNISTOGLFedDRiFedDRGridSearch.py` | **Refined parameter selection** | Searches proximal and relaxation parameters for FedDR and iFedDR. |
| `FEMNISTOGLFedNMapZhangGridSearch.py` | **Refined parameter selection** | Searches `gamma` and server learning-rate combinations for FedNMap and Zhang. |
| `FEMNISTOGLExperimentReplot.py` | Plotting helper | Rebuilds the final aggregate plots from completed main-experiment results. It is not required for training. |
| `ExperimentResults/` | Selected results | Archived main-experiment outputs for sampling levels 50, 100, and 200. |
| `FEMNISTOGLFedDRiFedDRGridSearch/` | Selected tuning results | Archived FedDR/iFedDR grid-search summaries and plots. |
| `FEMNISTOGLFedNMapZhangGridSearch/` | Selected tuning results | Archived FedNMap/Zhang grid-search summaries and plots. |

The three tuning programs document parameter selection. The main reported
results are generated by `FEMNISTOGLNeuralNetworkExperiment.py`.

```text

|-- Algorithms/
`-- FEMNISTNeuralNetworkOGL/

    |-- FEMNISTOGLStepsizeTest.py
    |-- FEMNISTOGLFedDRiFedDRGridSearch.py

    |       |-- mytrain.json                       # combined JSON option
    |       |-- mytest.json
    |       |-- all_data/                          # or LEAF all-data shards
    |       |-- train/                             # or LEAF train shards
    |       `-- test/                              # and LEAF test shards
```

Only one input format is required. Keep the raw dataset and newly generated
`Results/` directory outside version control.

## Main-experiment configuration

The default main experiment selects 200 writers, evaluates client-sampling
levels 200, 100, and 50, and uses a 784-128-62 neural network with Softplus
activation. It runs 200 communication rounds with 30 local updates and five
algorithm seeds. The activation can be changed to ReLU in the settings block.

## Supported data layouts

Set `DATA_DIRECTORY = Path("")` in each tuning script, or pass
`--data-directory` to programs that expose the command-line option. Supported
layouts include:

```text
FEMNIST/train-00000-of-00001.parquet
FEMNIST/mytrain.json
FEMNIST/mytest.json
FEMNIST/all_data/*.json
FEMNIST/train/*.json
FEMNIST/test/*.json
```

Parquet input requires `pyarrow`. LEAF-style JSON shards are merged by writer,
after which the experiment creates a reproducible within-writer train/test
split. Do not commit the raw FEMNIST dataset.

## Recommended parameter-selection workflow

1. Run `FEMNISTOGLStepsizeTest.py` to identify useful overall scales.
2. Run `FEMNISTOGLFedDRiFedDRGridSearch.py` to refine FedDR and iFedDR proximal
   and relaxation parameters.
3. Run `FEMNISTOGLFedNMapZhangGridSearch.py` to refine FedNMap and Zhang
   learning-rate parameters.
4. Transfer the selected settings to the algorithm-parameter block in the main
   experiment, then run the formal comparison.

## Running notes

Run with the repository root available on the Python import path. Configure
the data and result directories, then verify the device, activation, sampling
levels, local updates, round budget, seeds, and selected algorithm parameters.
The three tuning programs are optional when the stored settings are accepted.

FEMNIST uses settings-checked completed-result caches, not mid-run optimizer
checkpoints. Finished candidates and seeds can be reused, while an interrupted
unfinished candidate must be rerun. Do not reuse cached results after changing
the writer partition, model, or OGL configuration.

## Outputs

The main script writes new runs under
`Results/FEMNISTOGLNeuralNetwork/`, with a separate directory for each sampled
client count. It saves problem settings, the selected writer list, per-seed
algorithm results, mean-and-standard-deviation CSV files, and plots for loss,
accuracy, and inactive groups.

The main script uses `FEMNISTOGLExperimentReplot.py` after training to rebuild
a consistent final set of aggregate plots. This helper is included in the
directory but is not required for model training or completed-result caches.
